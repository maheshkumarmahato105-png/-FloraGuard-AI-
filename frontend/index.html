System Architecture & Model Transparency

About FloraGuard AI

FloraGuard AI is an end-to-end agricultural technology application designed to help farmers, agronomists, gardeners, and researchers identify plant leaf diseases early. Rather than relying on static demos, every prediction is generated live by a real PyTorch deep learning model trained and evaluated on the PlantVillage dataset.

Frontend

Responsive AgTech UI

HTML5, CSS3, Tailwind CSS, and modular ES6 JavaScript featuring WebRTC live camera switching, drag-and-drop uploads, and mobile image compression.

Backend API

Python & FastAPI

High-performance REST endpoints (/api/predict, /api/upload, /api/history, /api/health) with strict image validation and Pydantic schemas.

AI & Vision

PyTorch + OpenCV

Two-stage transfer learning with MobileNetV2 (and EfficientNet-B0 support), OpenCV HSV leaf focusing, sharpness/exposure quality checks, and confidence gating.

Database

SQLite → PostgreSQL

Powered by SQLAlchemy ORM with SQLite out of the box and one-line scaling to PostgreSQL via the DATABASE_URL environment variable.

AI Model & Training Methodology

1. Leak-Free Data Splitting

Images are verified for integrity and split strictly into 70% Training / 15% Validation / 15% Testing (group-aware across physical leaves when available) prior to any augmentation.

2. Transfer Learning & Augmentation

MobileNetV2 pretrained on ImageNet undergoes classifier warmup followed by full-backbone fine-tuning with random rotations, flips, color jitter, class-balanced cross-entropy loss, and cosine LR scheduling.

3. Honest Uncertainty Gating

During inference, softmax probabilities below the 60% reliability threshold—or severely dark/non-leaf photos—return an Uncertain response prompting a clearer photo instead of guessing.
